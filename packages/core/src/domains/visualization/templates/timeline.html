🧠 Welcome to Agent Brain Platform

Purpose: This extension helps AI coding agents (like Claude) become better partners by giving them persistent memory, your standards, and expert solutions. Transform forgetful juniors into consistent seniors.

📋 Quick Start (3 Steps)

Step 1: Create Knowledge

Switch to AB Knowledge tab → Click "+ Add Item" → Choose a type (Golden Path, ADR, Pattern, Learning) → Write your standards/patterns in markdown → Save to .agent-brain/

💡 Example: Document your auth pattern, API conventions, or testing requirements

Step 2: Install Bundled Templates

Go to AB Marketplace tab → Browse bundled templates → Find "Agent Brain Base" and "Reza Rezvani's CLAUDE.md Essentials" → Click "Install" on both

💡 These templates teach AI agents how to behave (honesty, session journals, clean code, etc.)

Step 3: Inject into CLAUDE.md

In AB Knowledge tab → Click scan icon 🔍 → Find your CLAUDE.md file → Select knowledge items → Click "Apply to File"

💡 Now AI agents automatically load this context every session - no more re-explaining!

🎯 How to Use Each Tab

📊 AB Timeline

  • View audit trail: See all commits, branches, PRs, knowledge items, and session events
  • Filter events: Click "Controls" button → Select event types, branches, authors, time range
  • Inspect details: Hover for tooltips, click events for detailed popup with multiple tabs
  • Navigate: Scroll/drag to move through time, use range selector for precise zoom

📚 AB Knowledge

  • Create items: Click "+ Add Item" → Fill metadata → Write markdown content
  • Save templates: Select items with checkboxes → Click "💾 Save Template"
  • Scan CLAUDE.md files: Click 🔍 icon → View all claude.md files in workspace
  • Apply templates: Select target file → Choose items → Click "Apply to File"

📝 AB Sessions

  • Create session journals: Make markdown file in .agent-brain/sessions/YYYY-MM/
  • Required frontmatter: id, title, startTime, endTime, summary, tags, filesModified
  • Appears on timeline: Sessions show as 📝 events at startTime
  • Best practice: Document multi-prompt AI sessions with 5+ exchanges

🏪 AB Marketplace

  • Browse templates: View bundled templates (included with extension) and user-created
  • Install templates: Click "Install" to add template items to your workspace
  • Publish templates: Save knowledge items as template → Share with team
  • Two essential bundles: "Agent Brain Base" (AI behavior) + "Reza Rezvani's Essentials" (CLAUDE.md structure)

💡 Key Concepts

Knowledge Items

Markdown files with YAML frontmatter storing standards, patterns, ADRs, learnings. These are the "training material" for AI agents.

Templates

Collections of knowledge items that can be installed as a group. Use templates to package expertise for reuse across projects.

CLAUDE.md Injection

Process of applying knowledge items to your CLAUDE.md file using HTML comment markers. AI agents automatically read this on startup.

Session Journals

Documented multi-prompt coding sessions with AI agents. Capture decisions, learnings, and context for future reference and timeline tracking.
